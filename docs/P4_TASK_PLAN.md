## 2. 方案选择

### 方案 A：人工植入缺陷（推荐，快速 baseline）

**时间**: 1-2 小时  
**成本**: 低  
**可信度**: 中（合成缺陷，但基于真实图纸结构）

#### 执行步骤

1. **选择 6 张基础图纸**（各类型各选 1-2 张）
   - 平面图 2 张：P-02, P-06（结构相对简单）
   - 系统图 2 张：S-01, S-02
   - 大样图 1 张：D-01
   - 泵房图 1 张：PUMP-01

2. **植入 3 类典型缺陷**（每类 4-6 个实例，共 15 个缺陷点）

   **类型 1：管径违规**（6 个）
   - 污水立管 DN100（应 ≥DN150，GB50015-2019 4.5.8）
   - 生活给水 DN15 服务 >8 户（应 ≥DN20，GB50015-2019 3.5.7）
   - 消防主管 DN80（应 ≥DN100，GB50974-2014 8.1.2）
   - 排水横管 DN50 坡度 0.01（应 ≥DN75，GB50015-2019 4.3.9）
   - 雨水立管 DN75（应 ≥DN100，GB50015-2019 4.9.9）
   - 通气管 DN40（应 ≥DN50，GB50015-2019 4.6.9）

   **类型 2：坡度违规**（5 个）
   - DN100 排水横管坡度 0.005（应 ≥0.012，GB50015-2019 4.3.9A）
   - DN150 排水横管坡度 0.006（应 ≥0.008，GB50015-2019 4.3.9A）
   - DN200 排水横管坡度 0.002（应 ≥0.004，GB50015-2019 4.3.9A）
   - 雨水管 DN100 坡度 0.003（应 ≥0.005，GB50015-2019 4.9.12）
   - 通气管水平段坡度 0.001（应 ≥0.01，GB50015-2019 4.6.11）

   **类型 3：材料违规**（4 个）
   - 生活饮用水用 PVC-U（应用不锈钢/铜管/PP-R，GB50015-2019 3.3.2）
   - 室内埋地排水用 PP-R（应用铸铁/UPVC，GB50015-2019 4.3.1）
   - 消防管用 PE（应用钢管，GB50974-2014 8.2.1）
   - 热水管用 UPVC（应用 PP-R/不锈钢，GB50015-2019 3.3.2）

3. **植入方式**（修改文本图元，保持图形结构不变）
   - 找到原图中正确标注的管径/坡度/材料文字（TEXT/MTEXT）
   - 用 `ezdxf` 修改文本内容为违规值
   - 另存为 `*_defect.dxf`（保留原图）
   - 每个缺陷记录：图纸 ID + 违规类型 + 违规值 + 对应条款 + TEXT entity handle

4. **建立 gold 标注**（`data/eval/drawing_p4_defects_gold.jsonl`）
   ```jsonl
   {"drawing_id": "P-02_defect", "defect_id": "P02-D001", "defect_type": "管径不足", "entity_handle": "1A3", "text_content": "污水立管 DN100", "violation": "污水立管管径应≥DN150", "clause": "GB50015-2019 4.5.8", "severity": "major"}
   ...
   ```

5. **运行审查链**
   ```bash
   python -m water_agent.cli review-drawing data/drawings/defect_samples/P-02_defect.dxf
   ```

6. **计算召回率**
   - Gold 缺陷总数：15（人工植入的已知缺陷）
   - 系统检出数：？（审查链实际报警数）
   - 召回率 = 检出数 / 总数
   - **目标**: ≥80%（12/15 以上）

#### 优势
- 快速（1-2 小时完成全流程）
- 可控（知道每个缺陷的确切位置和类型）
- 可重复（自动化脚本可批量生成）
- 覆盖典型违规类型

#### 劣势
- 合成缺陷，不是真实设计院出错场景
- 可能不够"隐蔽"（真实错误可能伴随上下文混淆）

---

### 方案 B：采集真实缺陷图纸（高可信度，但耗时）

**时间**: 3-5 天  
**成本**: 中高  
**可信度**: 高（真实设计错误）

#### 执行步骤

1. **来源渠道**
   - 设计院历史审图意见（已发现并修正的违规图纸）
   - 施工图审查机构案例库（脱敏后）
   - 教学案例（院校给排水设计课程的错误示例）

2. **采集要求**
   - 每张图纸至少含 1 个已确认的规范违规
   - 配合审图意见或专家标注
   - 完成脱敏流程（同 P2）

3. **建立 gold 标注**（同方案 A）

#### 优势
- 真实场景，可信度高
- 覆盖设计师实际易错点

#### 劣势
- 耗时长（涉及外部协调）
- 样本量可能不足
- 脱敏风险更高（真实项目图纸）

## 5. 验收标准

| 项 | 要求 | 验收方式 |
|---|---|---|
| Gold 缺陷数 | ≥10 个 | 检查 `drawing_p4_defects_gold.jsonl` |
| 覆盖缺陷类型 | ≥3 类 | 管径 + 坡度 + 材料 |
| 召回率 | ≥80% | `eval_recall.py` 报告 |
| 误报率 | ≤20% | 用 P2.5 阴性集测试 |
| 可重复 | 是 | 脚本化，可 CI 集成 |

## 7. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| 合成缺陷过于简单 | 召回率虚高 | 参考真实审图意见设计缺陷，避免"教科书式错误" |
| 植入破坏图纸结构 | 无法解析 | 只修改文本内容，不动图形几何 |
| Gold 标注有误 | 评测失效 | 人工复核每个缺陷，双人交叉验证 |
| 审查链性能不足 | 超时 | 限制单图审查时间，记录性能数据 |
