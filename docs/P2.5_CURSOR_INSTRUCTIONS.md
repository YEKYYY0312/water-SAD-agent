# P2.5 任务：人工标注真实图纸缺陷（Cursor 执行版）

## 任务概述

对 18 份真实图纸样本进行人工审查，标注出违反给排水设计规范的缺陷，建立 `drawing_p1` 评测集。

**资源**：
- 图纸样本：`data/drawings/real_samples/` (18 份 DXF)
- 规范文档：`data/specs/` (GB50015-2019 等)
- 参考格式：`data/eval/drawing_p0.jsonl`

---

## 标注范围（只标注这 6 类）

1. ✅ **管径不符**：管道标注的管径不符合规范要求
2. ✅ **标高不合理**：管道标高违反规范或冲突
3. ✅ **材料选用错误**：管道材料不符合使用场景
4. ✅ **坡度不足**：排水管坡度小于规范要求
5. ✅ **缺少必要设施**：缺少规范要求的附件或设备
6. ✅ **间距/位置不合规**：设施布置违反间距或位置要求

**不标注**：图纸完整性、制图规范、设计深度、计算类、系统性问题

---

## 标注格式

每张图纸一个 JSON 文件（示例）：

```json
{
  "drawing_id": "P-01",
  "drawing_type": "平面图",
  "annotation_date": "2026-09-15",
  "annotator": "人工审查",
  "total_defects": 2,
  "defects": [
    {
      "defect_id": "P-01-D001",
      "category": "管径不符",
      "severity": "高",
      "description": "生活给水立管 DN15 不符合规范要求",
      "location": {
        "layer": "给水",
        "approx_position": "1轴与A轴交点附近",
        "entity_type": "TEXT",
        "entity_content": "DN15"
      },
      "regulation": {
        "spec": "GB50015-2019",
        "clause": "3.5.2",
        "requirement": "生活给水立管管径不应小于 DN20"
      },
      "expected": "DN20 或更大",
      "actual": "DN15",
      "notes": "该立管服务 3 层住户，按用水定额计算流量应选用 DN20"
    }
  ]
}
```

**重点**：
- `defect_id`：唯一标识（格式：`{drawing_id}-D{序号}`）
- `location`：描述要具体，能在图纸上找到
- `regulation`：必须有规范依据（spec + clause + requirement）
- `expected` vs `actual`：明确对比

### Step 2: 审查并标注图纸

**审查顺序**（从易到难）：
1. 系统图 (S-01 ~ S-05)：简单，缺陷集中
2. 大样图 (D-01 ~ D-03)：细节清晰
3. 平面图 (P-01 ~ P-07)：内容复杂
4. 泵房图 (PUMP-01 ~ PUMP-03)：注意 PUMP-03 大量使用块

**对于每张图纸**：
1. 用 CAD 软件打开 `data/drawings/real_samples/{drawing_id}.dxf`
2. 对照规范逐项检查（管径、标高、材料、坡度、设施、间距）
3. 发现缺陷 → 查找规范条款 → 填写标注文件
4. 保存为 `data/eval/drawing_p1/annotations/{drawing_id}.json`

**快速检查清单**：

- [ ] **管径**：给水立管 ≥DN20，排水立管 ≥DN75，消防管 ≥DN100
- [ ] **标高**：给水管在排水管上方（净距 ≥0.15m）
- [ ] **材料**：热水不用 PVC，消防不用塑料，室外埋地不用镀锌钢
- [ ] **坡度**：DN100 排水 i≥0.012，DN75 i≥0.015，雨水 i≥0.005
- [ ] **设施**：排水立管有检查口，转角有清扫口，给水有水表
- [ ] **间距**：给排水管水平净距 ≥0.5m

### Step 3: 创建汇总脚本

```bash
cat > scripts/merge_drawing_annotations.py << 'EOFPY'
#!/usr/bin/env python3
"""汇总图纸标注为评测集 JSONL 格式。"""
import json
from pathlib import Path

def merge_annotations(annotations_dir: Path, output_file: Path):
    """将单图标注汇总为评测集。"""
    all_cases = []
    total_defects = 0
    
    for json_file in sorted(annotations_dir.glob("*.json")):
        with open(json_file, encoding="utf-8") as f:
            annotation = json.load(f)
        
        drawing_id = annotation["drawing_id"]
        total_defects += annotation["total_defects"]
        
        # 为每个缺陷生成一条评测案例
        for defect in annotation["defects"]:
            case = {
                "drawing_id": drawing_id,
                "defect_id": defect["defect_id"],
                "query": f"审查图纸 {drawing_id}",
                "gold_defects": [
                    {
                        "category": defect["category"],
                        "description": defect["description"],
                        "regulation": defect["regulation"],
                        "location": defect["location"],
                    }
                ],
                "metadata": {
                    "drawing_type": annotation["drawing_type"],
                    "severity": defect["severity"],
                }
            }
            all_cases.append(case)
    
    # 写入 JSONL
    output_file.parent.mkdir(parents=True, exist_ok=True)
    with open(output_file, "w", encoding="utf-8") as f:
        for case in all_cases:
            f.write(json.dumps(case, ensure_ascii=False) + "\n")
    
    print(f"✅ 生成评测集: {output_file}")
    print(f"   总图纸数: {len(list(annotations_dir.glob('*.json')))}")
    print(f"   总缺陷数: {total_defects}")
    print(f"   总案例数: {len(all_cases)}")

if __name__ == "__main__":
    annotations_dir = Path("data/eval/drawing_p1/annotations")
    output_file = Path("data/eval/drawing_p1.jsonl")
    merge_annotations(annotations_dir, output_file)
EOFPY

chmod +x scripts/merge_drawing_annotations.py
echo "✅ Step 3 完成"
```

### Step 4: 生成统计报告

```bash
cat > scripts/generate_drawing_p1_stats.py << 'EOFPY'
#!/usr/bin/env python3
"""生成 drawing_p1 标注统计报告。"""
import json
from pathlib import Path
from collections import Counter

def generate_stats(annotations_dir: Path, output_md: Path):
    """生成标注统计报告。"""
    
    # 统计数据
    stats_by_type = Counter()  # 图纸类型
    stats_by_category = Counter()  # 缺陷类别
    stats_by_severity = Counter()  # 严重程度
    total_drawings = 0
    total_defects = 0
    
    for json_file in sorted(annotations_dir.glob("*.json")):
        with open(json_file, encoding="utf-8") as f:
            annotation = json.load(f)
        
        total_drawings += 1
        drawing_type = annotation["drawing_type"]
        defect_count = annotation["total_defects"]
        total_defects += defect_count
        
        stats_by_type[drawing_type] += defect_count
        
        for defect in annotation["defects"]:
            stats_by_category[defect["category"]] += 1
            stats_by_severity[defect["severity"]] += 1
    
    # 生成 Markdown
    md_content = f"""# Drawing P1 评测集 - 真实图纸缺陷标注

**标注日期**: 2026-09-15  
**样本数**: {total_drawings} 张图纸  
**总缺陷数**: {total_defects} 条  
**平均密度**: {total_defects/total_drawings:.1f} 个/张  

## 按图纸类型统计

| 图纸类型 | 缺陷数 | 占比 |
|---------|--------|------|
"""
    
    for drawing_type, count in stats_by_type.most_common():
        pct = count / total_defects * 100
        md_content += f"| {drawing_type} | {count} | {pct:.1f}% |\n"
    
    md_content += f"""
## 按缺陷类别统计

| 缺陷类别 | 数量 | 占比 |
|---------|------|------|
"""
    
    for category, count in stats_by_category.most_common():
        pct = count / total_defects * 100
        md_content += f"| {category} | {count} | {pct:.1f}% |\n"
    
    md_content += f"""
## 按严重程度统计

| 严重程度 | 数量 | 占比 |
|---------|------|------|
"""
    
    for severity, count in stats_by_severity.most_common():
        pct = count / total_defects * 100
        md_content += f"| {severity} | {count} | {pct:.1f}% |\n"
    
    md_content += """
## 使用方法

```bash
# 运行评测
_venv/bin/python -m pytest tests/test_drawing_eval.py -k drawing_p1

# 查看单张图纸的标注
cat data/eval/drawing_p1/annotations/P-01.json | jq .
```

## 标注说明

详见各图纸的标注文件 (`annotations/*.json`)。

每个缺陷包含：
- 唯一 ID、类别、严重程度
- 具体位置描述（图层、近似位置、实体类型）
- 规范依据（规范编号、条款号、要求）
- 期望值与实际值对比
"""
    
    # 写入文件
    output_md.parent.mkdir(parents=True, exist_ok=True)
    with open(output_md, "w", encoding="utf-8") as f:
        f.write(md_content)
    
    print(f"✅ 生成统计报告: {output_md}")
    print(f"   总图纸数: {total_drawings}")
    print(f"   总缺陷数: {total_defects}")

if __name__ == "__main__":
    annotations_dir = Path("data/eval/drawing_p1/annotations")
    output_md = Path("data/eval/drawing_p1/README.md")
    generate_stats(annotations_dir, output_md)
EOFPY

chmod +x scripts/generate_drawing_p1_stats.py
echo "✅ Step 4 完成"
```

# 检查 JSON 格式
for file in data/eval/drawing_p1/annotations/*.json; do
    echo "检查 $file"
    jq empty "$file" || echo "❌ 格式错误"

_venv/bin/python << 'EOFPY'
import json
from pathlib import Path

annotations_dir = Path("data/eval/drawing_p1/annotations")
errors = []

for json_file in annotations_dir.glob("*.json"):
    with open(json_file, encoding="utf-8") as f:
        annotation = json.load(f)
    
    # 检查必填字段
    required_fields = ["drawing_id", "drawing_type", "total_defects", "defects"]
    for field in required_fields:
        if field not in annotation:
            errors.append(f"{json_file.name}: 缺少字段 {field}")
    
    # 检查每个缺陷
    for i, defect in enumerate(annotation["defects"]):
        required_defect_fields = ["defect_id", "category", "severity", 
                                  "description", "location", "regulation"]
        for field in required_defect_fields:
            if field not in defect:
                errors.append(f"{json_file.name}: 缺陷 {i} 缺少字段 {field}")

if errors:
    print("❌ 发现错误:")
    for error in errors:
        print(f"   {error}")
else:
    print("✅ 所有标注文件格式正确")
EOFPY

echo "✅ Step 6 完成"
```
