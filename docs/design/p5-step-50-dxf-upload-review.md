# P5-S50 规格：DXF 上传 → 程序化审查 → 进入对话

日期：2026-09-29　状态：实施中　前置：P5-S49（显式附件 + `file_context`）

## 问题

网页端对 DXF 完全不可用：上传白名单拒收 `.dxf`，`WebAgenticSessionFactory` 硬编码 `drawing_root=None`，compose 也没配 `DRAWING_ROOT`，上传卷和图纸目录互不相通。P3 的图纸链（读取 → 映射 → 规则 → 报告）只能在 CLI/harness 里用。

## 决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | **上传时同步跑确定性审查**（`run_drawing_review`），审查报告作为这份上传的"文本"入库：分块、召回、显式附件三条路径都复用 S48/S49，不另起一套 | 18 张真实样图实测：全图读取 + 映射 + 规则最慢 1.04 s（P-01，5,377 图元），不需要后台队列。报告是程序产物，与"抽取出的文字"同一地位 |
| D2 | **不给模型开放按 id 读 DXF 的工具**；Web 路径不注册 `read_drawing` | `read_drawing` 的 root 是单一扁平目录，按主体隔离需要每会话单独构造目录视图，而模型拿到的依然是原始图元，数值推导还得它自己做——审查报告才是给人看、给模型引用的正确粒度。工具 schema 预算和治理计数因此都不变 |
| D3 | 审查按**全图**跑（`max_entities` 提到 20,000），不用 CLI 默认的 500 | 默认 500 在真实图上全部截断（P-02 实测 791 个图元只审到 500），报告里"已审查管段"会系统性偏少。20,000 覆盖 17/18 张样图；超出时报告里如实写明截断 |
| D4 | 原图字节照 S48 保留在上传卷；审查读取的是 `{upload_root}/{upload_id}/drawing.dxf`（固定文件名），root 就是该上传自己的目录 | 用户文件名可能是中文或以 `_` 开头，过不了 `drawing_id` 正则。固定名 + 单文件 root 让 `resolve_drawing_path` 与 `read_dir_allowed` 两道路径防线原样生效，并且物理上只能读到这一个文件 |
| D5 | 魔数：ASCII DXF 要求首个非空白组码为 `0` 且其后是 `SECTION`；二进制 DXF 要求前缀 `AutoCAD Binary DXF\r\n\x1a\x00`；DWG（`AC10xx`）明确拒收并给出"请另存为 DXF"的提示 | `.dxf` 是文本格式，没有固定魔数；只看扩展名会让任意文本冒充图纸。DWG 属于 S51 |
| D6 | 解析失败（`DRAWING_UNREADABLE` 等）→ **上传失败**（`UPLOAD_EXTRACTION_FAILED` + 原错误码），不留下没有报告的图纸记录 | 与 S48 纪律一致：记录存在就必须可用 |
| D7 | 审查报告的正文**不改写**：P3 的表述纪律（`Finding.rendered_finding()` 唯一出口、`not_checked` 独立小节、`pipes_reviewed == 0` 不写合规措辞）原样进入提示词 | 这些措辞是刻意设计的，模型转述时才不会把"未检查"读成"没问题" |
| D8 | 图纸里的文字仍当作**数据**：报告只来自规则引擎，图元文字不进报告正文；`suspicious` 图元数写进报告头，并同步到上传记录的 `suspicious` | 与 P3"注入标注不参与数值推导、但如实披露"一致 |
| D9 | `file_context` 的能力说明改为"DXF：上传后自动做程序化审查，结论与未检查项见附件报告"；DWG 仍写"暂不支持，请另存为 DXF" | 能力说明由运行时推导（S49 D），这里由上传白名单是否含 `.dxf` 推导 |

## 不做（本步）

- DWG 读取（S51，LibreDWG）；CAD 导出 PDF 的视觉审阅（S52）。
- 修改 P3 规则、映射或标注关联半径；真实图纸召回率仍为 blocked（gold 只有 2 条）。
- 图纸预览渲染。

## 验收

- 上传一张真实样图（P-02）→ 201，`suffix=.dxf`，`chunk_count>0`，预览以 `== 图纸审查报告` 开头。
- 附上该图纸提问"审查这张图" → `【用户附件】` 里是审查报告，包括未检查项。
- 伪装成 `.dxf` 的普通文本、DWG 改名为 `.dxf`、空文件 → 400，且不入库。
- 前端能选择 `.dxf`；上传后的卡片显示"已审查 N 条管段，发现 M 条问题，K 项未检查"。
- `ci_gate.sh` 全绿；工具 schema token 与 `governance_coverage()` 不变。
