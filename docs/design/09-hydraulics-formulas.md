# 水力计算公式口径表（V0.1）

> 本文档是水力计算工具族的**唯一口径来源**，先于代码落地。所有计算项在此写明：适用场景、输入/输出单位、公式、系数来源、适用范围、默认值是否允许、缺参策略、越界策略。
> 对应 ADR-01：**公式由输入显式指定，禁止静默切换**。任何新增/修改口径必须先改本文档。
>
> 口径依据：给排水设计通用公式 + 相关规范（GB 50015《建筑给水排水设计标准》、GB 50013《室外给水设计标准》、GB 50014《室外排水设计标准》）。**具体数值口径以本文档为准，不随实现者判断漂移。**

## 通用约定

- 所有公式输入采用 **SI 制 + 工程常用单位**，见各条。
- 常量：重力加速度 `g = 9.81 m/s²`；圆周率 `π`。
- **缺参策略**（所有计算项一致）：缺少必要参数 → 返回结构化 `missing_inputs`（列出缺失参数名），**禁止猜测/补默认值**。
- **越界策略**（所有计算项一致）：物理/范围校验不通过 → 结果照常计算，但返回 `assumptions` 标注越界项与建议，**由上层明示给用户**；若参数无物理意义（如负管径、负流量），视为缺参/非法输入。
- **默认值是否允许**：除下述显式标注的默认值外，一律不允许静默默认。

## 1. 流速计算 `velocity`

| 项 | 口径 |
|---|---|
| 适用场景 | 满管流圆管的断面平均流速（给水管道、排水压力/重力满管管段） |
| 输入 | `flow_lps` 流量 L/s；`diameter_mm` 管内径 mm；`scenario` 场景（可选，默认 `water_supply`） |
| 输出 | `velocity_mps` 流速 m/s |
| 公式 | `v = 4·Q / (π·d²)`（Q 换算为 m³/s，d 换算为 m） |
| 系数来源 | 几何关系 `Q = A·v`，圆管 `A = πd²/4`；无经验系数 |
| 适用范围 | 满管流；非满管流不适用（排水重力流请用 `slope_manning`） |
| 默认值 | `scenario` 默认 `water_supply`（显式允许，见约束）；`flow_lps`/`diameter_mm` 不允许默认 |
| 缺参策略 | 缺 `flow_lps` 或 `diameter_mm` → `missing_inputs` |
| 越界策略 | **场景约束非全局硬编码**：按 `scenario` 取约束并写入 `assumptions` 标注——<br>· `water_supply`（给水）：常用区间 0.6–1.5 m/s（GB 50015/设计手册"常用区间之一"），越界仅标注不拦截<br>· `drainage`（排水）：最小设计流速 0.6 m/s（污水管，GB 50014）；最大设计流速按管材（金属 10 m/s、非金属 5 m/s，GB 50014），**超出上限返回 `assumptions` 严重警告** |
| 判分 | 相对误差 ≤1% 且绝对误差 ≤0.001 |

## 2. 沿程水头损失 `head_loss_*`

三个显式公式口径，互不切换。**摩阻系数/粗糙系数的来源必须在调用时显式给出或按本节固定取值。**

### 2.1 Darcy-Weisbach `head_loss_darcy_weisbach`

| 项 | 口径 |
|---|---|
| 适用场景 | 满管有压流（给水管网）；摩阻系数已知（来自穆迪图/管材表/实验） |
| 输入 | `length_m` 管长 m；`diameter_mm` 内径 mm；`velocity_mps` 流速 m/s；`friction_factor` 摩阻系数 f（无量纲）；`gravity_mps2`（可选，默认 9.81） |
| 输出 | `head_loss_m` 沿程水头损失 m |
| 公式 | `hf = f · (L/d) · (v²/(2g))` |
| 系数来源 | **`friction_factor` 必须由调用方显式提供**（来自穆迪图/管材粗糙度表）；不内置自动求 f 的隐式 Colebrook 迭代（口径不锁定） |
| 适用范围 | 满管有压流；层流/湍流均可用给定 f 计算 |
| 默认值 | `gravity_mps2` 默认 9.81（显式允许）；其余不允许默认 |
| 缺参策略 | 缺 `length_m`/`diameter_mm`/`velocity_mps`/`friction_factor` 任一 → `missing_inputs` |
| 越界策略 | `friction_factor < 0` 非法；`f ≤ 0` 按非法输入处理 |

### 2.2 Hazen-Williams `head_loss_hazen_williams`

| 项 | 口径 |
|---|---|
| 适用场景 | 满管有压流，水温 10–20°C 给水管网近似计算（SI 单位制） |
| 输入 | `length_m` 管长 m；`diameter_mm` 内径 mm；`flow_lps` 流量 L/s；`hazen_williams_c` 粗糙系数 C（无量纲） |
| 输出 | `head_loss_m` 沿程水头损失 m |
| 公式 | `hf = 10.67 · L · Q^1.852 / (C^1.852 · d^4.8704)`（Q 为 m³/s、d 为 m、hf 为 m） |
| 系数来源 | **`hazen_williams_c` 由调用方显式提供**；参考取值：PVC/PE 150、铸铁 130、钢管 120（按管材表，此处不内置） |
| 适用范围 | 满管有压流，SI 单位制；非满管/压力流不符不适用 |
| 默认值 | 不允许（`hazen_williams_c` 必须显式给） |
| 缺参策略 | 缺任一输入 → `missing_inputs` |
| 越界策略 | `C ≤ 0` 非法 |

### 2.3 舍维列夫（Shevelev）`head_loss_shevelev`

| 项 | 口径 |
|---|---|
| 适用场景 | 给水钢管/铸铁管，满管有压流的经验公式（国内给水设计常用） |
| 输入 | `length_m` 管长 m；`diameter_mm` 内径 mm；`velocity_mps` 流速 m/s |
| 输出 | `head_loss_m` 沿程水头损失 m |
| 公式 | 水力坡度 i（m/m）：<br>· 当 `v ≥ 1.2 m/s`：`i = 0.00107 · v² / d^1.3`<br>· 当 `v < 1.2 m/s`：`i = 0.000912 · v² · (1 + 0.867/v)^0.3 / d^1.3`<br>然后 `hf = i · L`（d 为 m） |
| 系数来源 | 舍维列夫经验公式（给水钢管/铸铁管，水温 10°C 附近）；系数 0.00107/0.000912/0.867 为公式常数 |
| 适用范围 | 给水钢管、铸铁管满管流；管径适用范围按公式经验取 DN50–DN1000 |
| 默认值 | 不允许 |
| 缺参策略 | 缺任一输入 → `missing_inputs` |
| 越界策略 | `v ≤ 0` 非法；`d ≤ 0` 非法 |
| 判分 | 相对误差 ≤1% 且绝对误差 ≤0.001 |

## 3. 管径计算 `diameter`

| 项 | 口径 |
|---|---|
| 适用场景 | 已知设计流量与设计流速，求所需管径（给水/排水压力管选型初算） |
| 输入 | `flow_lps` 流量 L/s；`velocity_mps` 设计流速 m/s |
| 输出 | `diameter_mm` 计算内径 mm（不自动圆整到标准管径；圆整属上层决策） |
| 公式 | `d = sqrt(4·Q / (π·v))`（Q 为 m³/s，d 为 m） |
| 系数来源 | 几何关系 `Q = A·v`；无经验系数 |
| 适用范围 | 满管流；要求 `v > 0` |
| 默认值 | 不允许 |
| 缺参策略 | 缺 `flow_lps` 或 `velocity_mps` → `missing_inputs` |
| 越界策略 | `v ≤ 0` 非法；`Q ≤ 0` 非法（无物理意义） |
| 判分 | 相对误差 ≤1% 且绝对误差 ≤0.001（对 mm 值） |

## 4. 排水坡度（非满流曼宁）`slope_manning`

| 项 | 口径 |
|---|---|
| 适用场景 | 排水重力流非满管流，求管底坡度（GB 50014 排水管道水力计算） |
| 输入 | `flow_lps` 流量 L/s；`diameter_mm` 内径 mm；`fill_ratio` 充满度 h/d（0<h/d<1）；`manning_n` 曼宁粗糙系数 n；`gravity_mps2`（可选，默认 9.81） |
| 输出 | `slope` 坡度（m/m，无量纲） |
| 公式 | 过水断面几何（圆管非满流，θ 为湿周半角 rad）：<br>· `θ = 2·arccos(1 - 2·(h/d))`<br>· 过水面积 `A = (d²/8)·(θ - sinθ)`（d 为 m）<br>· 湿周 `P = (d/2)·θ`；水力半径 `R = A/P`<br>· 曼宁：`Q = (1/n)·A·R^(2/3)·S^(1/2)`<br>· **坡度 `S = (n·Q / (A·R^(2/3)))²`** |
| 系数来源 | 曼宁公式；n 由调用方显式提供（参考：混凝土 0.013、PVC/U 0.009–0.011、铸铁 0.013） |
| 适用范围 | 非满流圆管（0<h/d<1），重力流；`fill_ratio=0.5` 为半满流典型工况 |
| 默认值 | `gravity_mps2` 默认 9.81；`manning_n` 不允许默认（必须显式） |
| 缺参策略 | 缺任一必要输入 → `missing_inputs` |
| 越界策略 | `fill_ratio` 超出 (0,1) → 非法输入；`n ≤ 0`、`d ≤ 0`、`Q ≤ 0` 非法 |
| 判分 | 相对误差 ≤1% 且绝对误差 ≤0.0001（坡度数值小，绝对阈值相应缩小） |

## 5. 泵扬程 `pump_head`

| 项 | 口径 |
|---|---|
| 适用场景 | 水泵装置所需扬程计算（09-next-steps 阶段 B 明确为 P1 能力） |
| 输入 | `static_head_m` 几何扬程 m；`friction_head_m` 沿程水头损失 m；`local_head_m` 局部水头损失 m；`residual_head_m` 剩余水头（出水自由水头）m |
| 输出 | `pump_head_m` 泵扬程 m |
| 公式 | `H = H_static + H_friction + H_local + H_residual`（各分量相加；`friction_head_m`/`local_head_m` 由上游 `head_loss_*` 等计算提供，此处不重复计算） |
| 系数来源 | 能量方程（伯努利）；无经验系数 |
| 适用范围 | 泵装置扬程初算；各分量单位均为 m |
| 默认值 | 不允许（四项必须显式；需要某分量为 0 时显式传 0） |
| 缺参策略 | 缺任一分量 → `missing_inputs` |
| 越界策略 | 任一分量 < 0 → 非法输入 |
| 判分 | 相对误差 ≤1% 且绝对误差 ≤0.001 |
