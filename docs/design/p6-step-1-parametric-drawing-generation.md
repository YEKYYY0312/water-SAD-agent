# Spec: P6-S1 参数化 DXF 图纸生成（给水系统）

> 状态：待用户确认。本 Step 交付「计算参数 → 成套 DXF 图纸」的最小闭环：单栋建筑给水系统，含平面图、系统图、大样图。排水与消防后续 Step 扩展。

## Objective

用户输入给水设计参数（管径、流量、管材、楼层数、立管位置），Agent 自动生成三张 DXF 图纸：
1. **平面图**：各层给水管道平面布置
2. **系统图**：给水系统轴测图（立管 + 横管 + 支管）
3. **大样图**：关键节点（阀门井、水表井、穿楼板）详图

生成结果可下载，可导入 CAD 软件编辑。

## Problem

当前系统只能**读** DXF 和**审查** DXF，不能**生成** DXF。用户需要：
- 计算完成后直接出图，而不是手动画
- 生成的图纸能进 AutoCAD/天正继续编辑
- 图纸质量达到「设计院实习生水平」——不错误、可施工、需复核

## Decisions

### D1 输入契约：结构化参数 + 自然语言混合

**方式**：先计算，再生成，人工可调整（混合模式）

用户输入（Web 表单或对话）：
```json
{
  "system_type": "给水",
  "building_type": "住宅",
  "floors": 6,
  "units_per_floor": 2,
  "riser_position": "楼梯间",
  "main_pipe": {"dn": "DN50", "material": "PPR"},
  "branch_pipe": {"dn": "DN25", "material": "PPR"},
  "flow_rate_lps": 2.5,
  "pressure_mpa": 0.35
}
```

Agent 流程：
1. 参数校验（`calc_*` 工具验证水力计算合理性）
2. 生成图纸几何数据（程序化，非 LLM）
3. 渲染 DXF（ezdxf）
4. 返回下载链接 + 图纸摘要（供用户确认）

### D2 图纸内容生成：程序化规则引擎

**建筑类型支持**（用户已拍板：同时支持三种）：
- **住宅**：标准层，每层 2-4 户，立管在楼梯间或管道井
- **办公**：开敞办公区，立管在核心筒，支管沿走廊吊顶
- **商业**：大空间，立管在边角，支管沿柱网

**平面图**（每层一张，或标准层一张）：
- 轴线网格（默认 3.6m × 3.6m 柱网，可调）
- 立管位置标记（用户指定或规则默认）
- 横管走向（沿墙/沿梁底/沿吊顶，按建筑类型规则）
- 阀门、水表位置（按规范间距）
- 标注：管径、标高、坡向

**系统图**：
- 立管贯穿各层
- 每层支管连接
- 阀门、水表、减压阀位置
- 管径变化节点
- 标高标注

**大样图**（关键节点）：
- 水表井大样（1:20 比例）
- 阀门井大样
- 管道穿楼板大样
- 按建筑类型选关键节点（住宅：水表井；办公：吊顶内阀门组；商业：泵房接管）

**规则来源**：
- `GB50015-2019` 建筑给水排水设计标准
- 既有 `drawing/rules.py` 的审查规则反向利用（知道什么是错的，就知道什么是对的）
- 建筑类型差异化规则表（`building_type_rules.json`，可配置）

### D3 DXF 生成技术：ezdxf + 图层规范

**复用现有**：`drawing/synth.py` 已有 `build_synthetic_drawing()`，但那是测试用的简单图形。本 Step 扩展为生产级生成器。

**图层规范**（与审查器兼容）：
```
WS-PIPE-MAIN      给水主管
WS-PIPE-BRANCH    给水支管
WS-VALVE          阀门
WS-METER          水表
WS-TEXT           标注
WS-DIM            尺寸标注
```

**块（BLOCK）**：
- 阀门符号（闸阀、截止阀、球阀）
- 水表符号
- 立管编号圆圈

**输出质量**：
- 单位：毫米（`$INSUNITS=4`，与审查器兼容）
- 文字样式：仿宋_GB2312，字高 3.5mm
- 线型： continuous（实线），中心线用 CENTER
- 图纸版本：R2010（AC1024，AutoCAD 2010+ 兼容）

### D4 与现有系统集成

**计算前置**：
- 用户必须先完成水力计算（`calc_velocity`、`calc_pipe_diameter` 等）
- 计算结果自动带入图纸参数（`flow_rate`、`dn`、`material`）

**审查后置**：
- 生成图纸后，自动触发 `review_drawing` 规则引擎
- 审查结果附在下载页：「本图纸经自动审查，发现 0 条缺陷 / 3 条警告」
- **无 HITL 阻断**（用户已拍板）：生成后直接下载，人工在 CAD 里再改

**导出格式**：
- 三张 DXF 打包为 ZIP 下载
- 同时提供 PDF 预览（用 `ezdxf.addons.drawing` 渲染为 PNG，再转 PDF）

### D5 不做什么

- 不做排水系统（后续 Step）
- 不做消防系统（后续 Step）
- 不做建筑结构图（梁板柱，只画管道）
- 不做三维建模（BIM/Revit）
- 不做自动标注尺寸（只标管径和标高，不标长度）
- 不做图纸目录、图签、会签栏（这些由设计院模板决定，Agent 不猜）

## Testing

### 单元测试

- `test_drawing_generator.py`：
  - 输入合法参数 → 生成 3 张 DXF，文件存在且非空
  - 输入非法参数（负流量、零管径）→ 结构化错误
  - 生成的 DXF 可被 `dxf_reader.py` 解析（闭环测试）

### 集成测试

- 计算 → 生成 → 审查 全链路：输入参数 → 计算合格 → 生成图纸 → 审查通过

### 冒烟

- Web 端：填参数 → 点击「生成图纸」→ 下载 ZIP → 解压后三张 DXF 均可打开

## Risks

- **R1 布局规则过于简单**：真实设计院的管道布置考虑因素很多（结构梁高、吊顶空间、其他专业管线），本 Step 只做「沿墙敷设」一种规则，复杂场景需要人工调整。
- **R2 图纸美观度**：自动生成的图纸「能看但不够好看」，距离设计院出图标准有差距。这是预期内的，Agent 的定位是「实习生初稿」，不是「所长签字」。
- **R3 规范合规性**：生成规则基于 GB50015-2019，但规范更新频繁，规则需要人工维护。
