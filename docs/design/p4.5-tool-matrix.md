## 2. MCP 动态工具（P4 网关）

- 统一能力：`Capability.MCP_INVOKE`（**默认无主体持有**，装配期显式授予）。
- 登记：`inventory.register_mcp_tool_binding(McpToolBinding(tool_name=mcp_<server>_<tool>, server_id, remote_tool, capability=MCP_INVOKE, requires_human_confirmation))`，只增不删，重名 `MCP_NAME_COLLISION`。
- 桥接名：`mcp_<server>_<tool>`，≤41 字符，超长截断+8位哈希后缀。
- 暴露条件（两把钥匙）：配置 `allow` 白名单含该工具（精确匹配，`None` 全拒）**且**主体被授予 `MCP_INVOKE`。
- 投毒防御：`mcp/schema.py::ensure_description_safe`（NFKC+零宽剥离+折叠+400截断后过 `rules.detect_injection`，命中即 `MCP_DESCRIPTION_UNSAFE` 不暴露）；`inputSchema` 仅确定性子集（`object/properties/required` + `string/integer/number/boolean` + `minimum/maximum/minLength/maxLength/default/enum` + 自由 `object{array, additionalProperties:true}`/`array` 透传，`anyOf可空` 归一，其余 `anyOf/oneOf/$ref/pattern` 等不支持即 `MCP_UNSUPPORTED_SCHEMA`）。
- 确认门：`MCPServerConfig.human_confirmation=true && confirmation_handler_ready=false` 时整台 `MCP_CONFIRMATION_UNAVAILABLE` 不暴露不 spawn（P4.5 沿用，Step 26 才翻为 interrupt）。
- `data/mcp_servers.json` 实测基线（darwin, 2026-09-10）：`autocad_mcp 8 工具`（drawing/entity/layer/block/annotation/pid/view/system）护栏放行；`revit_python 7 工具`因确认门整台拒绝（预期正确）。

## 3. 四 Agent 最小工具视图（编排器分发，非 Agent 自选）

| Agent | 可见工具（最小） | 不可见工具 | 允许/禁止行为（任务书 §4/§8） |
|---|---|---|---|
| **hydraulic** 水力计算 | `calc_velocity`（含现有 `tools/hydraulics.py` 的多公式内核：舍维列夫/Darcy-Weisbach/Hazen-Williams/曼宁等，`hydraulic_cases[].formula` 显式指定）+ 参数解析（只读，不新增工具） | `retrieve_clauses / cite_clauses / material_stats / read_drawing`、全部 MCP、文件写入/最终发布 | 允许：参数解析、调用本地水力工具、复述工具数值、记录 assumptions；禁止：编造缺参、直接写设计方案/图、引用未检索条款、导出文件 |
| **design** 工程设计 | `retrieve_clauses / cite_clauses` + `material_stats` 只读预检（不写盘） | `calc_velocity`、全部 MCP、文件写入/最终发布 | 允许：形成系统方案/管段拓扑/材质与管径说明、声明 `unresolved_items`；禁止：自算水力、改 `CalcPackage`、编造 `source_id`、静默默认材质/系统/单位/标高/流量 |
| **review** 设计监控 | `cite validator / docgen self-check / read_drawing → map_pipes → review_drawing` + `stale/provenance/not_checked` 检测器（只读） | 全部写工具、MCP 危险工具、设计修改 | 允许：调用确定性自检/引用校验/图纸审查/跨产物一致性检查；禁止：改任何被审查产物、调写工具、替代人工批准、把 `not_checked` 写成 `pass` |
| **drawing** 综合绘图 | `material_stats` 聚合 + `docgen` 模板 + `DrawingPlan` 渲染 + 草图执行窄适配器（`ezdxf` staging）+ `read_drawing` 回读 | `calc_velocity`、任意 MCP 水力重算、未授权路径、直接最终发布 | 允许：合并上游事实、生成 `DrawingPlan`（`LINE/POLYLINE/TEXT/MTEXT + $INSUNITS`）、经 `ezdxf` 产 staging、回读验证；禁止：重算水力、改设计选型、猜真实建筑坐标、批准前发布最终文件；`integration_conflicts` 非空时不产正式候选 |

**执行期约束**：

- Agent 之间只传 `ArtifactEnvelope`（Pydantic `extra="forbid"`），不传完整消息历史；检索/图纸/MCP 返回统一 `SourceTag.TOOL_OUTPUT/RETRIEVED_*`，永不提升为 `SYSTEM_POLICY/USER_MESSAGE`，产物文本仍过输入/输出护栏。
- 模型不能填 `artifact_id / payload_hash / approval / release` 状态与真实文件路径；`output_file_id` 由编排器给，真实 `staging/final` 路径装配期解析。
- `ReviewIssue.owner` 是路由唯一输入（`hydraulic | design | drawing | human`），多 owner 按 `hydraulic → design → drawing → human` 依赖顺序串行；新 `CalcPackage` 使 `Design/Drawing/Doc/Review` 全 stale，新 `Design` 使 `Drawing/Doc/Review` stale，新 `Drawing` 使 `DrawingPackage/Review` stale。
- 触发水力重算的字段（任务书 §7.2）：`flow_lps / diameter_mm / length_m / velocity_mps / friction_factor / hazen_williams_c / manning_n / fill_ratio / static_head_m / friction_head_m / local_head_m / residual_head_m` 及影响它们的拓扑/单位变化，结构化比对判定，不由 LLM 以"影响不大"跳过。
