**规格**: `docs/design/13-p3-drawing-review.md`

**影响范围**:
- `src/water_agent/drawing/dxf_reader.py`
- `tests/test_dxf_reader.py`
- 相关工具链路

### 验收标准

- [ ] PUMP-03 的 3,285 个 INSERT 块全部展开
- [ ] 块内几何实体（LINE/CIRCLE/ARC）可见
- [ ] 块内文本实体（TEXT/MTEXT）可见
- [ ] 块嵌套正确处理（递归展开）
- [ ] 块变换正确应用（旋转/缩放/位移）
- [ ] 性能可接受（单张图纸 < 5 秒）
- [ ] 测试覆盖：PUMP-03 作为真实测试样例

### 技术要点

**使用 ezdxf 的 `virtual_entities()` 方法**:

```python
import ezdxf

doc = ezdxf.readfile("PUMP-03.dxf")
msp = doc.modelspace()

for entity in msp:
    if entity.dxftype() == 'INSERT':
        # 展开块参照
        for virtual_entity in entity.virtual_entities():
            # virtual_entity 是展开后的实体
            # 已应用块的变换（位移/旋转/缩放）
            process_entity(virtual_entity)
```

**注意事项**:
1. `virtual_entities()` 返回生成器，需遍历
2. 展开后实体已应用块变换，坐标是最终坐标
3. 块可能嵌套（块里引用块），`virtual_entities()` 递归处理
4. 块定义可能被多个 INSERT 引用，每个 INSERT 独立展开
5. 匿名块（`*U` / `*D` 前缀）需要特殊处理

## P4 召回率验收准备

### 方案 A：人工植入缺陷（推荐，快速）

**步骤**:

1. **复制图纸副本**
   ```bash
   mkdir -p data/drawings/implanted_samples
   cp data/drawings/real_samples/*.dxf data/drawings/implanted_samples/
   ```

2. **用 CAD 软件修改副本**（建议修改 5-7 张图纸，每张植入 2-3 个缺陷）
   
   **缺陷类型建议**:
   
   | 类型 | 植入方式 | 规范依据 | 预期难度 |
   |-----|---------|---------|---------|
   | 管径不符 | DN100 改 DN50 | GB50015-2019 §3.5.2 | 易检出 |
   | 坡度不足 | i=0.012 改 i=0.008 | GB50015-2019 表4.3.5 | 中等 |
   | 材料错误 | 热水管 PPR 改 PVC | GB50015-2019 §3.5.4 | 易检出 |
   | 标高冲突 | 给水管 -0.5 / 排水管 -0.4 | GB50015-2019 §3.8.11 | 难检出 |
   | 缺少设施 | 删除排水立管检查口 | GB50015-2019 §4.8.4 | 中等 |

3. **记录植入点**（创建 `implanted_annotations.json`）
   ```json
   {
     "drawing_id": "P-01-implanted",
     "implanted_defects": [
       {
         "defect_id": "IMPL-001",
         "category": "管径不符",
         "location": "1轴与A轴交点，给水立管",
         "modification": "DN100 → DN50",
         "regulation": "GB50015-2019 §3.5.2",
         "expected_detection": "高"
       }
     ]
   }
   ```

4. **生成评测集**
   ```bash
   python scripts/generate_implanted_eval_set.py
   # 产出: data/eval/drawing_p2_implanted.jsonl
   ```

**预计时间**: 1-2 小时  
**优点**: 快速、可控、覆盖多种缺陷类型  
**缺点**: 不是真实缺陷，更像合成测试集

### 方案 B：采集带缺陷图纸（真实，慢）

**步骤**:

1. **联系设计院**
   - 获取历史施工图审查退回件（已有缺陷记录）
   - 确保已脱敏（移除业主/项目信息）

2. **按 P2 流程处理**
   ```bash
   # DWG → DXF 转换
   bash scripts/convert_dwg_batch.sh data/drawings/defective_originals/
   
   # 脱敏处理
   python scripts/desensitize_drawings.py
   
   # PII 扫描
   python scripts/scan_drawing_pii.py --check-all
   
   # 验证可读性
   python scripts/verify_drawing_samples.py
   ```

3. **人工标注真实缺陷**
   - 用 CAD 软件打开，对照原审查意见
   - 标注每个缺陷的位置、规范条款
   - 创建 `annotations/*.json`

4. **生成评测集**
   ```bash
   python scripts/merge_drawing_annotations.py
   # 产出: data/eval/drawing_p2_real.jsonl
   ```

**预计时间**: 3-5 天  
**优点**: 真实缺陷，gold 标注质量最高  
**缺点**: 需要外部资源，时间较长

## 评测指标目标

### P4 验收标准

**召回率（Recall）**: ≥ 80%
- 定义: (检出的缺陷数) / (gold 标注的缺陷数)
- 计算: 逐张图纸计算，取加权平均

**误报率（FPR）**: ≤ 5%
- 定义: (误报的缺陷数) / (阴性样本总数)
- 数据: drawing_p1 阴性集（18 张干净图纸）

**精确率（Precision）**: ≥ 70%
- 定义: (真阳性) / (真阳性 + 假阳性)
- 备注: 精确率偏低可接受（宁可误报，不可漏报）

### 分类别目标

| 缺陷类型 | 召回率目标 | 备注 |
|---------|-----------|------|
| 管径不符 | ≥ 85% | 文本明确，易检出 |
| 材料错误 | ≥ 85% | 文本明确，易检出 |
| 坡度不足 | ≥ 75% | 需要解析坡度标注 |
| 标高冲突 | ≥ 60% | 需要空间计算，难 |
| 缺少设施 | ≥ 70% | 需要全局分析 |
| 间距不合规 | ≥ 65% | 需要距离计算 |
