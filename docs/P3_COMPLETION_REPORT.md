## 技术实现

### 核心改动

**文件**: `src/water_agent/drawing/dxf_reader.py`

**主要修改**：

1. **添加 `_extract_entity()` 统一分派函数**
   - 支持 `source_block` 参数（记录来源块）
   - 递归处理 INSERT 嵌套
   - 统一错误处理

2. **修改主循环处理 INSERT**
   ```python
   if entity.dxftype() == 'INSERT':
       for virtual_entity in entity.virtual_entities():
           extracted = _extract_entity(virtual_entity, source_block=entity.dxf.name)
           if extracted:
               entities.append(extracted)
   ```

3. **更新所有 `_extract_*()` 函数**
   - 添加 `source_block: str | None = None` 参数
   - 在返回字典中包含 `source_block` 字段

4. **更新数据模型**
   - `DrawingEntity` 添加 `source_block` 字段
   - 保持向后兼容（`None` 表示不来自块）

### 关键技术点

1. **使用 ezdxf 的 `virtual_entities()`**
   - 自动处理坐标变换（位移/旋转/缩放）
   - 自动递归展开块嵌套
   - 生成器模式，内存友好

2. **错误处理**
   - 展开失败不中断整体解析
   - 记录到 `errors` 列表
   - 实测：0 个展开错误

3. **性能优化**
   - `virtual_entities()` 按需计算
   - 不预加载全部块定义
   - PUMP-03 仅需 0.4 秒（远低于 5 秒目标）
