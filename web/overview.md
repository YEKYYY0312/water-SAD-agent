# water-agent · 前端设计方案 v2（agent 工作台）

交付物：`web/index.html` — 单文件可交互原型，零依赖。
上一版（浅色 AI 聊天套壳）存档为 `web/v1-light-prototype.html`。

> **数据声明**：原型中的规范条文均为**占位示例**，不是真实规范文本（引用行上标注「占位」）。
> 接入真实语料前，任何条款文字都不得进入 UI —— 这是项目第二条铁律「引用可追溯，禁止编造条款」。

---

## v1 → v2 改了什么

v1 的问题不是配色，是**物种错了**：大圆角 + 蓝白卡片 + 阴影 = 标准 AI 聊天产品。而这个项目的本质是**本地 agent 工作台**，使用者是在干活的工程师，不是来聊天的人。

| | v1 聊天套壳 | v2 agent 工作台 |
|---|---|---|
| 形态 | 三栏聊天 | 顶栏 + 工作区侧栏 + 会话流 + inspector + 状态栏 |
| 圆角 | 12 ~ 16 | 3 ~ 5（近零） |
| 层级 | 卡片阴影堆叠 | 1px hairline + 背景明度差 |
| 字体 | 中文 sans 为主 | 标识符/参数/路径/数值全走等宽，中文 sans |
| 状态 | 彩色圆角徽章 | 符号 `✓ ✗ ! ▸ ·` + 单色描边小标 |
| 密度 | 宽松 | 紧凑（22px 树行、20px 日志行、26px 状态栏） |
| 左侧 | 会话列表 | 工作区文件树 + 会话（双 tab） |
| 新增 | — | 模式/权限策略、⌘K 命令面板、吞吐状态栏、genui 图表 |

## 1. 视觉语言：深色终端工作台

**核心原则：界面自己退后，让内容（数值、条款、日志）站前面。**

- **色**：深底 `#0B0D12`，面板 `#101319`，hairline `#1E2431`。主色 `#4D8DFF` 只用于主操作、引用标识与当前选中项，全屏彩色占比 < 5%。语义色仅出现在状态符号与 1px 边框上，不做大面积色块填充。
- **字**：`JetBrains Mono` 优先，承载工具名、参数、路径、条号、耗时、token、状态栏 —— 等宽字符构成的"日志流"是工作台质感的主要来源。中文正文仍用 `PingFang SC`，避免中英混排崩坏。
- **线**：一切分隔用 1px hairline，不用阴影分层级。浮层（命令面板、toast）才动用阴影。
- **符号**：`✓` 成功 `✗` 失败 `!` 警告 `▸` 执行中 `·` 待执行 `›` 列表 `❯` 提示符 `ƒ` 计算 `◇` trace。
- **小标签**：分区标题用 10px 等宽大写 + `.12em` 字距 + 尾部延长线（`.kicker`），这是工作台味的关键细节。
- **主题**：深/浅双套令牌，顶栏一键切换。浅色不是"反色"，而是独立校准的一套（背景转 `#F6F7F9`，主色转 `#2563EB`）。

## 3. 从 DSH 搬来的工作台要素

| DSH 要素 | 本项目的落法 |
|---|---|
| VSCode 式侧边栏（文件树/终端/Git） | 工作区文件树，按类型着色（`.md` 蓝 / `.db` 紫 / `.py` 青 / `.jsonl` 绿），点击进右侧预览面板 |
| 四种模式 | 顶栏模式选择：标准 / PTC / 极简 / 创造 |
| 三级权限（只读 / 工作区可写 / 完全访问） | 顶栏权限策略 + breadcrumb 上的实时标签；选「完全访问」时选择器转为琥珀警示色 |
| genui（回复内渲染图表与交互组件） | 计算回答内嵌**流速–管径关系曲线**（SVG 手写，阴影带 = 合理流速区间，虚线 + 圆点标出当前工况），随参数实时重算 |
| 动态插件 / 面板 | 命令面板 ⌘K，命令带分组标签（session / harness / index / ui / perm / mode） |
| 实时吞吐统计 | 底部状态栏 ctx / tok / **tps**，生成中 tps 抬升 |
| 皮肤中心 | 顶栏主题切换（深/浅两套令牌） |
| 左下角设置 | 顶栏设置入口 |

## 4. 组件的终端化重做

| 组件 | 形态 |
|---|---|
| 工具调用 | 终端日志块：`▸ tools 7 steps 1.42s`，展开后左侧竖线 + 缩进，每行 `符号 工具名 入参摘要 耗时` |
| 规范引用 | 左侧 2px 主色竖条的行（非卡片），`规范号 §条号` + 标题 + 校验徽标 + score，hline hover 高亮 |
| 计算卡片 | 表格式参数 → 虚线框公式 → 结果区（27px 等宽数值 + 单位 + 右侧校验结论），标注「程序化内核」 |
| 审批门 | 琥珀 1px 边框 + 低饱和底，`[y] 确认生成` / `[n] 返回修改`，确认后锁定并提示写入 trace |
| 输入区 | `❯` 提示符 + 自适应高度，底部 hint 用 `kbd` 样式标注快捷键 |
| 消息操作 | 有用 / 无用 / 复制 / 重生成 / trace，全部 11px 等宽，hover 才出现背景 |

## 5. 沉淀到界面的项目铁律

1. **计算不交给模型** —— 计算卡显式标注「程序化内核」；`validate → 超界 → revise → 重算 → 通过` 的回环在工具日志里逐步点亮，肉眼可见。
2. **引用可追溯** —— 引用行带「已校验 / 待确认 / 未命中」徽标；原型内条文一律标注「占位」，点击引用卡跳右侧面板并高亮。
3. **人工确认** —— ADR-04：生成正式文档前弹审批门，可回滚。
4. **反馈即飞轮** —— 点「无用」→ `已回流评测集 · rag_p0`。

## 6. 可访问性

- `:focus-visible` 1px 主色描边；树/会话/tab/命令项全部可键盘到达。
- 会话流 `role="log"` + `aria-live="polite"`，选择器带 `aria-selected`，审批与反馈带 `aria-pressed`。
- 状态不单靠颜色：符号 + 文案 + 色三重编码。
- `prefers-reduced-motion` 下关闭全部动画。

## 7. 接口约定（沿用 `docs/design/05-frontend.md`）

| 接口 | 落点 |
|---|---|
| `POST /api/chat`（SSE） | 会话流、工具日志逐步点亮 |
| `POST /api/upload` | 输入区附件 chip |
| `GET /api/tools` | 工具日志的名称/入参 |
| `GET /api/spec/:ref` | 引用行展开、右侧预览 |
| `POST /api/feedback` | 消息操作行 |
| `GET /api/run/:id/trace` | 右侧 trace 面板 |

事件名沿用现有 Trace：`run_start / node_enter / node_exit / retrieve_complete / generate_complete / citation_check_complete / retry / error / run_end`。

## 8. 下一步

1. 拆成 Vite + React + TS，令牌原样迁 CSS 变量，`.kicker` / `.row` / `.ref` 直接转组件。
2. 先接 `GET /api/run/:id/trace`（本地 JSON Trace 现成），inspector 先跑真实数据。
3. 接 SSE：工具日志由 `node_enter/node_exit` 事件驱动，而不是前端模拟。
4. **计算卡只渲染后端返回的 `result + unit + formula + check`，前端不做任何数值运算** —— 当前原型里的公式计算与曲线绘制仅为演示效果，正式版必须删掉。
