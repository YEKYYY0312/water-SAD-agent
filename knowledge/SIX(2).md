（三）计算程序
1.木模板
（1）根据荷载组合得出单位面积的总荷载
（2）绘制支设草图，假定木材断面尺寸及间距
（3）根据木结构设计规范，计算挠度。核算木材数据
（4）绘制模板图
2.组合钢模板
（1）得出ΣP（KN/m2）
（2）确定对拉螺栓的直径及间距
（3）确定后背管间距，不大于50cm
（4）绘制模板支设图，便于人工组装

五.模板的拆除
不承重的侧模：不致损坏表面和棱角，可拆除
承重的模板：达到一定强度，才能拆除
拆模要求
| 部位 | 跨度 | 砼强度标准值 |
| --- | --- | --- |
| 板 | L≤2 | 50% |
|  | 2<L≤8 | 75% |
| 梁，拱，壳 | L≤8 | 75% |
|  | L>8 | 100% |
| 悬臂构件 | L≤2 | 75% |
|  | L>2 | 100% |

拆模程序：后支先拆，先支后拆，先拆除非承重部分，后拆除承重部分。
六.模板支设的质量要求
（一）模板及支撑结构材料、质量应符合规范规定、设计要求。
（二）支撑应有足够的强度、刚度和稳定性。在浇灌时不变形。
（三）便于装拆，损耗少，周转快。安装时要检查构件是否牢固，在浇灌过程中要经常检查。
（四）基土应坚实，并有排水设施。
（五）复杂的混凝土结构应做配板设计，包括平面分块图，组装图，支撑系统图等。
（六）支架的设计和配制，应根据工程实际而定，以定型模板为主，尽量少用散板。

七.脱模剂
目的：为减少模板与构件的粘接。
种类：

水类（海藻酸钠加滑石粉加水）
树脂类（甲醛硅树脂）
