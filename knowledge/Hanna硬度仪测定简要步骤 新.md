# Hanna硬度仪测定简要步骤 新

Hanna 硬度仪测定简要步骤

一、测定器材和药品：

硬度仪，药剂（A 试剂、B 试剂、C 试剂、显色剂 ND），附带塑料吸管和小注射器。从

外形看，A 试剂用棕色大瓶，B 试剂为白色小瓶，ND 试剂为棕色小瓶，C 试剂为小方纸袋。

二、测定步骤：

1.  用试剂附带的 1ml 注射器，准确取 0.5ml 样品到测试瓶中，然后再加 0.5 毫升 ND 试

剂（显色指示剂）；

2.  用塑料吸管加 A 试剂到测试瓶，加到 10ml 刻度线。然后再加入 B 试剂 2 滴，再盖

上盖子摇匀；

3.  把测试瓶放入测量槽，注意对准方向，保证瓶盖上的切口确实插入仪器的凹槽中。

按下  ZERO/READ，显示屏开始调零倒计时，显示屏将出现 0 字样。

4.  从测量槽中取出测试瓶，加入一袋 C 试剂，拧紧管盖，轻轻摇匀。

5.  重新将水样放入测量仪中，按下“ZERO/READ”读数，液晶显示屏上将出现读数为总

硬度(CaCO3mg/L)

6.  按下 UNIT 键，分别以 F、D、E 为单位读数。(注：mg/L 硬度和法国度(FD)、德国

度(DD)、英国度(ED)之间的换算如下：1 mg/L =0. 1 FD=0.5556 DD=0. 07ED：)

7.  按下 RANGE 键准备下一次测量。

三、关于药剂种类和测量档位

1.  本硬度仪有三个档位：P1、P2 和 P3。P1 低档位，硬度 0~250mg/L，P2 中档位，适

用于 200~500 mg/L，P3 为高硬度测量档，适于硬度 400~750 mg/L。

2.    A 试剂有三种，分别是低浓度范围 A-LR、中浓度范围 A-MR 和高浓度范围 A-HR。

对应不同的水样，应采用响应的档位和药剂。

一般，自来水原水硬度较高，最高可能达到 400 mg/L 以上，此种水样，硬度仪采用 P3

档，试剂 A 采用 A-HR 型号。或者也可以试用 P2 档和 A-MR 试剂型号。

软化后的低硬度水样，应可采用 P1 档，同时试剂 A 选用 A-LR 型号。

注意事项：

1. 硬度试剂有皮肤刺激性，测试硬度应带手套保护皮肤，有接触皮肤时，迅速用自来

水进行冲洗；

2. 取样和加药的注射器和吸管，应专药专用，不要混用从而造成污染。
