# 13价值工程

第六章      价值工程

第一节     概述
一.价值工程的产生
六大管理技术：全面质量管理，系统工程，工业工程，行为科学，网络计划技术，价值工程
二.价值工程的概念
价值V：评价事物的有益程度的尺度。
价值=功能/成本
V=F/C
功能F：产品的用途和作用。
成本C：为实现产品的功能所消耗的劳动。
据公式分析如何提高价值？

概念
价值工程----用最低的寿命周期总成本，可靠地实现产品或服务的必要功能，并且着眼于功能分析的有组织的活动。
目的：提高产品的功能，降低产品的成本。

产品是广义的概念。

4.ABC分析法
      把对象的零件按成本7：2：1和数量1：2：7的比率，分为三类：
| 类别 | 成本比率% | 数量比率% |
| --- | --- | --- |
| A | 70-80 | 10-20 |
| B | 20 | 20 |
| C | 10-20 | 70-80 |
决策：选择A作为改进对象。

5.强制确定法
        通过计算三个系数来确定改进对象。

三个系数：
功能评价系数=零部件的功能得分/全部零部件功能得分
成本系数=各零部件目前成本/全部零部件目前成本之和
价值系数=功能评价系数/成本系数
决策：

      对于价值系数小于1的对象应提高功能，降低成本，做为主要改进对象。

第三节    功能分析、整理、评价

一.功能分析
（为价值工程的核心）
功能:某个产品或零件在整体中所担负的职能或所起的作用.
功能分类：
基本功能和辅助功能
必要功能和不必要功能
使用功能和美学功能

二.功能整理

1.明确基本功能，辅助功能等。
2.明确各功能间的相互关系
方法一：“此功能是如何实现的？”
方法二：“此结构的目的是什么”
3.绘制功能系统图

三.功能评价
                            功能评价：对功能的价值进行测定或评定，
                            是对功能的定量分析。
功能价值：找出实现某必要功能的最低成本，通过与实现这一功能的现实成本相比较，求二者的比值。
功能价值V=实现必要功能的最低成本F/实现该功能的现实成本C
V=F/C
V<1，E<0,应列为改善对象。
V=1为理想状态。
V>1，E>0，不用改善。

四.方案的评价与选择

概略评价：对所提出的许多方案进行粗略的分析和筛选。
详细评价：对概略评价筛选后的方案再具体化，通过进一步的调查研究和技术经济分析，选出令人满意的方案。
技术评价(功能实现性）
经济评价（费用节省性）
社会评价（社会效益性）

评价内容包括

1.评分法
1)请专家对各方案功能打分，从高至低。

2)然后求每个方案总分。比较。
例：很理想方案：4分，好的方案：3分，过得去的方案：2分，勉强过得去：1分，不行：0分。然后按下式计算：
X—技术价值系数；
P —各方案满足功能的得分值；
Pmax —各方案满足功能的最高得分；Pmax=4
n —各方案需要满足的功能数。

然后计算经济价值系数：Y
H理—理想成本；
H----新方案预计成本。
然后计算综合评价系数：K
K大为佳。
2.评判表法
确定评判要素（决定产品竞争能力的主要因素）。
确定各要素的比重（权重）。
作评判表进行评判。
