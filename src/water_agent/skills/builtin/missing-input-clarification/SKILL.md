# 缺参澄清

1. **列出缺什么**：逐项写出缺少的参数名称与单位（例如"设计流量，单位 L/s"），不要笼统地说"信息不足"。
2. **说明为什么需要**：每个参数后用一句话说明它在计算里的作用，帮助用户判断去哪里找。
3. **不给默认值**：不猜测、不代填典型值，也不先按假设值算一个结果再让用户确认。
4. **以工具为准**：计算工具返回 missing_inputs 时，按它列出的缺参逐项询问；返回 assumptions 时，把每条假设告诉用户并请其确认。
5. **一次问全**：把本轮能确定的缺参一次列完，避免来回多次追问。
