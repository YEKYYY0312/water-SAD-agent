# 计算书编写步骤

1. **澄清已知量**：逐项列出本次计算需要的输入（如管内径、设计流量、计算场景），标出用户已给出的和还缺的。缺参时先按 missing-input-clarification 规程向用户询问，不代填默认值。
2. **检索依据**：用 retrieve_clauses 检索与本次计算相关的条文（计算方法、取值要求、限值要求）。检索不到依据的项目，如实写"未检索到依据"。
3. **只用工具出数**：所有数值一律由 calc_velocity 等计算工具算出。复述计算结果时照抄工具输出的数值与单位，不改写、不四舍五入、不补算。工具返回 missing_inputs 时回到第 1 步；返回 assumptions 时在计算书里逐条写明。
4. **结论对照条文**：把工具算出的结果与检索到的条文要求逐项对照，说明是否满足。条文里的数值以检索结果原文为准。
5. **声明引用**：每一条依据都经 cite_clauses 声明引用；检索结果标注为非正式语料的，计算书里同样标注其非正式性质。
6. **计算书结构**：按"计算依据、已知条件、计算过程（工具输出）、结论、待补资料"五部分组织。
