# 规范规定不一致时的处理

1. **分别检索**：对涉及的每一本规范分别用 retrieve_clauses 检索，确认各自的原文规定；只依据检索到的原文，不凭记忆补充条文。
2. **并列引用**：把各本规范的规定并列写出，每一条都经 cite_clauses 声明引用，标明出自哪本规范。
3. **说明口径差异**：指出差异来自适用范围、建筑类型、设计阶段还是版本新旧；检索结果里的版本状态（是否现行）要一并说明。
4. **不自行裁决**：不替用户决定"取严"或"取哪本"；说明需要由设计人按项目所在地要求和适用范围确定，必要时提示核对正式出版标准与地方规定。
5. **检索不全时如实说明**：某一本规范没有检索到相关条文，就写明"未检索到"，不推测其规定。
